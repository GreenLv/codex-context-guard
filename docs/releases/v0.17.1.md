# Context Guard 0.17.1 — 2026-11-09

## English

### Highlights

- Copy private task state into the stable entry when you choose to move it. The migration tool starts with a read-only plan. If two sessions share an ID but contain different data, it keeps the existing target and isolates the source copy. Restore removes only unchanged copies created by that run. Legacy sessions stay with their original runtime. [Migration tool](https://github.com/GreenLv/codex-context-guard/blob/v0.17.1/tools/GUARD_STATE_MIGRATION.md)
- Use the stable entry after upgrading from the 0.16.1 public ZIP or its local wrapper, or upgrade an existing 0.17.0 stable entry in place. The 0.15.1 route follows its historical compatibility contract. Finish tasks that still need their old runtime before switching. [Upgrade guide](../UPGRADE_0_17_1.md)
- Installation leaves private task state where it is. The nine Hook events, schema 13, Stop protocol 5.0.0 and ordinary tool behavior carry forward from 0.17.0.

### Changes

- The repository maintains the native upgrade toolkit. POSIX sh and PowerShell 5.1/7 launch the same Python implementation and record the exact source, artifact and host inputs.
- Windows regressions cover separate process and PowerShell working directories, and access-control entries for an explicit user versus the owner-rights principal.

### Validation

- Source checks, the historical incident library, macOS and Windows native tests, package parity, performance, CI and the HOL scan each bind to their own inputs. Exact release evidence and tested boundaries are recorded separately. [Acceptance record](../LOCAL_ACCEPTANCE.md)

## 简体中文

### 要点

- 可按需把私有任务状态复制到稳定入口。迁移工具先生成只读计划。同 ID 的会话内容不同时，保留目标原件并隔离源副本。恢复只移除本次迁移创建且内容未变的副本。旧格式会话留在原运行时。[迁移工具](https://github.com/GreenLv/codex-context-guard/blob/v0.17.1/tools/GUARD_STATE_MIGRATION.md)
- 通过 0.16.1 公开 ZIP 或本地包装安装的用户可切换到稳定入口。已用 0.17.0 稳定入口的用户可原地升级。0.15.1 按既有兼容约定处理。请先结束仍依赖旧运行时的任务。[升级指南](../UPGRADE_0_17_1.zh-CN.md)
- 安装保留私有任务状态原有位置。九个 Hook 事件、状态格式 13、Stop 协议 5.0.0 和普通工具行为沿用 0.17.0。

### 变更

- 原生升级验收工具由仓库维护。POSIX sh 和 PowerShell 5.1/7 启动同一份 Python 实现，记录实际使用的源码、制品和宿主输入。
- Windows 固定回归新增两类覆盖。其一是进程工作目录与 PowerShell 当前位置分离，其二是区分显式用户与所有者权限条目的访问控制。

### 验证

- 源码检查、历史事故库、macOS 和 Windows 原生测试、制品一致性、性能、CI 和 HOL 扫描分别绑定各自的输入。正式发布的验收依据和适用边界单独记录。[验收记录](../LOCAL_ACCEPTANCE.md)
