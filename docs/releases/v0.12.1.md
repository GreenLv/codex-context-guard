# Context Guard 0.12.1

## English

Context Guard 0.12.1 removes redundant push confirmation from its Skill guidance
and reduces repeated workflow instructions and tests. Hook behavior and public
protocols remain unchanged.

### Highlights

- When you request an ordinary push and its repository, remote and branch are
  clear, Codex proceeds without asking you to repeat the target. The runtime
  already supported this; the Skill now agrees. Unresolved, conflicting or
  changed targets still need clarification.
- Ordinary tasks read a shorter Skill entrypoint. Advanced proof, authorization,
  migration and control instructions load through explicitly routed references.
- Completion guidance keeps the current work unit and required descendants in
  scope, preserving ancestor constraints without reopening historical work.
- A selected full current-behavior suite no longer reruns its covered public,
  runtime, conformance and installer test subsets. Standalone and independent
  native checks remain available.

### Upgrade and validation

Upgrade through the managed installer and start a fresh task to load the new
Skill. Existing tasks may continue using their immutable 0.12.0 cache. Ordinary
push permission does not include force-push, branch deletion or release publication.

Four new synthetic regressions cover plain push, commit-and-push, unresolved
upstreams and target/action expansion. Source checks, macOS and Windows isolated
install/parity/lifecycle acceptance, Candidate CI, HOL and public readback remain
separate evidence surfaces. The unchanged 0.12.0 host-behavior and performance
results retain their original identities. Normal user-runtime installation is
separate from candidate acceptance and publication.

See the [English changelog](../../CHANGELOG.md) for the complete changes.

## 简体中文

Context Guard 0.12.1 去掉 Skill 中重复确认推送目标的要求，并减少重复读取的工作流说明和测试。Hook 行为与公开协议保持不变。

### 主要变化

- 你要求普通推送，且仓库、远端和分支明确时，Codex 直接执行，不再要求重复陈述目标。运行时本已支持这一点，本次修正不一致的 Skill 说明。目标无法确定、存在冲突或发生变化时仍需澄清。
- 普通任务读取更短的 Skill 入口；高级证明、授权、迁移和控制说明通过明确的引用按需加载。
- 完成说明围绕当前工作单元及必要子项，保留祖先约束，不因历史未完成项重新开启当前任务。
- 已选中完整现行测试套件时，不再重复运行其中的公开合同、运行时、一致性和安装器子集；独立检查与原生检查继续保留。

### 升级与验证

通过受管安装器升级后，启动新任务加载新版 Skill。已有任务可以继续使用不可变的 0.12.0 缓存。普通推送授权不包含强制推送、删除分支或发布版本。

新增四项合成回归覆盖普通推送、提交并推送、无法确定的上游，以及扩大目标或动作授权。源码检查、macOS 和 Windows 隔离安装/一致性/生命周期验收、Candidate CI、HOL 与公开读回各自保留证据。未变的 0.12.0 宿主行为与性能结果保持原身份。正常用户环境的安装与候选验收、发布分别记录。

完整变更见[中文更新日志](../../CHANGELOG.zh-CN.md)。
