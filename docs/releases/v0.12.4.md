# Context Guard 0.12.4

## English

### Highlights

- Finishing a child task no longer makes the whole task look complete. Outstanding work still needs its own evidence.
- Follow-up instructions preserve the unfinished task and its limits. Phrases such as “retry after correcting the permission boundary” no longer look like requests to replace a requirement.
- Confirmations clear only the matching pause. “The model is ready” does not clear a separate wait for a file check.
- After compaction or resume, recovery lists current requirements first and makes their full text available, including the end of long requirements.
- Commit-and-push keeps to the authorized files. A later request to push the current candidate uses that verified commit instead of expecting another commit to be created.

### Changes

- Upgrade through the managed installer, then start a fresh task. Keep older caches for tasks that still use them, including the unpublished 0.12.2 and 0.12.3 trial versions.
- Private state moves to schema 11; schemas 10 and 9 migrate, while 7/8 remain read-only. Downgrading must not discard schema-11 data. The nine Hooks and Python 3.10+ requirement are unchanged.

### Validation

The recorded runtime passed independent macOS and Windows installation and portable checks, plus six host-behavior checks on each platform. These results retain their original run identities. Final-commit CI, HOL scanning, and public tag/Release verification are recorded separately in the [acceptance record](https://github.com/GreenLv/codex-context-guard/blob/v0.12.4/docs/LOCAL_ACCEPTANCE.md).

[Full changelog](https://github.com/GreenLv/codex-context-guard/blob/v0.12.4/CHANGELOG.md).

## 简体中文

### 重点

- 子任务结束不会再被当成整个任务完成；剩余工作仍需各自的完成证据。
- 补充指令会保留未完成任务及原有限制。“权限边界修正后重试”这类说法不会再被误认成替换需求。
- 确认只解除对应的暂停。例如，“模型已换好”不会解除另一项文件校验等待。
- 压缩上下文或恢复会话后，优先恢复当前要求，并可续读完整正文，长要求末尾的限制也会保留。
- 提交并推送只包含获授权的文件。随后要求推送“当前候选提交”时，会使用这个已验证的提交，不再错误地等待创建另一个提交。

### 变更

- 通过受管安装器升级后，启动新任务。旧任务仍需的缓存请继续保留，包括未发布的 0.12.2、0.12.3 试运行版本。
- 私有状态升级到 schema 11；schema 10、9 可迁移，7/8 保持只读。降级不能丢弃 schema 11 数据。九个 Hook 和 Python 3.10+ 要求不变。

### 验证

已记录的运行时分别通过 macOS、Windows 的安装与 portable 检查，以及各平台六项真实宿主行为检查；这些结果保留原始运行身份。最终提交的 CI、HOL 扫描和 tag/Release 公开核验分别记录，详见[验收记录](https://github.com/GreenLv/codex-context-guard/blob/v0.12.4/docs/LOCAL_ACCEPTANCE.md)。
